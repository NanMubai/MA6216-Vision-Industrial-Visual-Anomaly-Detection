# Failure-case analysis tables

Generated by `scripts/analysis_failures.py` from the saved outputs of the `padim_wrn50` and `patchcore_wrn50` runs (results/<run>/<category>/). Thresholds are the stored normal-validation values; test labels and masks are used only to describe the fixed predictions. Maps and masks are at the 224x224 evaluation crop, so region areas are fractions of the crop (the dataset analysis reports areas at the original full resolution).
